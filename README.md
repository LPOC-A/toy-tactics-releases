# Toy Tactics downloads

[Download the latest Windows version](https://github.com/LPOC-A/toy-tactics-releases/releases/latest)

Download the Windows ZIP, choose **Extract all**, then open **ToyTactics.exe** inside the extracted folder. Keep the whole folder together. You do not need a GitHub account, the source repository, Godot, .NET, or development tools.

The game shows its version and an **Updates** button in the top-right corner. Updates include patch notes and **Update and restart** between battles. Downloads and update metadata are signed by the publisher; the Windows preview itself is not Authenticode-signed, so Windows may show an unrecognized-app prompt.

**Internet rooms are awaiting hosting deployment in the initial preview.** The first build supports local two-player battles and LAN/direct connections. Once the room service is deployed, an in-game update will enable **Create private room** and **Join room** with an eight-character code. Keep the host running for the whole live battle and replay.

The ZIP includes **START HERE.md** with controls and troubleshooting. Each release includes a SHA256 checksum and signed update metadata. Only download game files from this repository's Releases page.

This repository contains downloads and release information. The game source repository remains private.
